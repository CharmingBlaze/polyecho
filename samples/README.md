# Engine hand-off sample

`engine-handoff.glb` is the character fixture from `src/core/export/engineHandoffScene.ts` (UVs, painted 8×8 PNG, two bones, Walk + Idle, Walk `footstep` marker).

```bash
npm run handoff:glb
```

Open the file in Godot 4, Unity, or Blender. Checklist: `docs/ENGINE_HANDOFF.md`.
